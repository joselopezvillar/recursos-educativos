# Iniciación ao desenvolvemento de webs con Vue.Js

## Titor
Juan Carlos Pérez González, profesor de CF na familia profesional de Informática e Comunicacións no IES de Teis de Vigo

## Obxectivos do curso
O principal obxectivo deste curso é iniciarnos no desenvolvemento web utilizando o framework Vue.js. Ao longo do curso, traballaranse os conceptos clave de Vue.js, entre os que destacamos:

Estrutura dos compoñentes: Comprenderás como é a organización dos compoñentes en Vue.js.
- Reactividade: Explorarás o sistema de reactividade de Vue.js, que permite que a túa aplicación se actualice de maneira automática cando cambian os datos.
- Enrutamento: Veremos como Vue.js manexa o enrutamento entre as diferentes páxinas da aplicación.
- Comunicación entre compoñentes: Aprenderás como os diferentes compoñentes de Vue.js interactúan entre si e como compartir datos entre eles de maneira eficiente.
- Operacións CRUD (Crear, Ler, Actualizar, Eliminar): Finalmente, veremos como xestionar datos na nosa aplicación a través das operacións CRUD, que son fundamentais para calquera aplicación web dinámica.

## Estrutura
O curso está estruturado en 4 tmódulos (1 por semana). 

- Módulo 1: apertura 20 de abril
- Módulo 2: apertura 23 de abril
- Módulo 3: apertura 27 de abril
- Modulo 4: apertura  4 de maio

Un consello é botar unha ollada o enunciado das tarefas antes de comezar co tema: así saberemos con antelación o que se vos pide para superar o módulo. E, polo tanto, os puntos onde vos debedes centrar.

## Metodoloxía
No módulo 1 traballaremos cos conceptos básicos de Vue con exemplos sinxelos. A partir do módulo 2, a nosa aprendizaxe atellarase nun proxecto (ABP).  Empezaremos cun proxecto sinxelo que irá medrando ao longo do curso. A medida que avancemos, iremos implementando os conceptos que aprendas de maneira práctica, engadindo funcionalidades que darán forma ao proxecto. Este enfoque permitirá que poidas aplicar de inmediato o que aprendas en cada módulo.

## Avaliación do progreso
Ao final de cada un dos catro módulos, farás unhas tarefas prácticas sinxelas. Estas tarefas estarán deseñadas para reforzar os coñecementos adquiridos e poñelos en práctica.
